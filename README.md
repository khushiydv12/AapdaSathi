# AapdaSathi 🌏🚨

**An AI-Powered Disaster Risk Intelligence and Relief Coordination System**

## Overview

AapdaSathi is a full-stack disaster management project developed for Smart India Hackathon (SIH) 2026. It explores how software, risk analysis, mapping, and relief-demand intelligence can support disaster preparedness and emergency response, with a focus on Northeast India.

The project brings together citizen-facing safety features, disaster-risk assessment, map-based interfaces, and relief resource management in one integrated system.

## Key Components

- Disaster Risk Engine: A Python-based risk engine for disaster-related risk assessment.
- Relief Intelligence: Components focused on relief demand and resource management.
- Map Interface: A dedicated map UI to support geographic visualization.
- Citizen Safety Interface: A frontend component focused on citizen safety.
- Full-Stack Architecture: Separate frontend, backend, AI-related, and shared modules.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Risk Analysis: Python
- Other Technologies: See the project configuration files for the complete dependency list.

## Project Goals

- Explore technology-driven disaster risk assessment.
- Support disaster preparedness and citizen safety.
- Improve visibility into relief demand and resource coordination.
- Bring relevant information together through map-based interfaces.

## Project Context

AapdaSathi was developed as a team project for Smart India Hackathon (SIH) 2026. Our team was not selected for the next stage. The project nevertheless provided experience in collaborative software development and exploring technology-based approaches to a real-world problem.
